![Создание папки](https://github.com/L1ghtsitte/formula_gerona/blob/main/photo%2Fgeron_2.jpg)

![Git Bush](https://github.com/L1ghtsitte/formula_gerona/blob/main/photo%2Fgeron_1.jpg)

Создадим пустой проект на Git Hub

![Проект на Git Hub](https://github.com/L1ghtsitte/formula_gerona/blob/main/photo%2Fgeron_3.jpg)

Скопируем команды (для ssh) из появившевося окна и вставим их в консоль

![Команды](https://github.com/L1ghtsitte/formula_gerona/blob/main/photo%2Fgeron_4.jpg)

![Создание Readme.md](https://github.com/L1ghtsitte/formula_gerona/blob/main/photo%2Fgeron_5.jpg)
